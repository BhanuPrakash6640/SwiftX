Part 1 · How Sift reads

Every word updates a small notebook

Sift doesn't reread the text it has already seen. It keeps a fixed-size notebook, shown here as a grid of columns. For each new word it does two things. First it lets the old notes fade a little. Then it writes something about the new word. Important words fade old notes faster and write strongly. Filler words like "the" barely change anything.

This demo guesses importance with a simple rule: names and long words matter, and short common words don't. The real Sift learns its own importance values (called Δ, "delta") during training. The update math is the real one: new notes = fade × old notes + Δ × what this word writes.

Part 2 · Three architectural paradigms

Transformer looks back at everything. Mamba updates a notebook. SiftX adds an eidetic memory shelf.

The Transformer compares each new word with every word before it (quadratic compute & memory). Mamba (Sift) does one continuous notebook update per word (linear speed, but fading memory). SiftX (Ours) unites both: the continuous linear stream of Mamba with a bounded 64-slot photographic memory shelf and straight-through read gate.

    Part 4 · SiftX Architecture

    Conquering the Fading Memory Frontier with Dual-Stream Intelligence

    Pure selective state spaces (like Mamba) are mathematically forced to blur past tokens into a single continuous recurrent vector. While ideal for general language syntax, this leads to catastrophic failure on exact associative recall: when asked to retrieve a specific number or key from hundreds of tokens ago, pure SSMs collapse to ~2% random guessing.

    Stream 1: Continuous Intuition (SSM)

    Multi-timescale channels handle fast local grammar and smooth semantic context with zero token-to-token comparisons.

    Stream 2: Bounded Memory Shelf (64 Slots)

    Maintains an exact photographic buffer of crucial facts, updated via surprise/relevance without unconstrained quadratic attention.

    A learned straight-through binary gate monitors incoming tokens and decides whether to open the memory shelf. By skipping lookups on routine words, SiftX saves ~70% of compute while guaranteeing photographic precision when queries arrive.
